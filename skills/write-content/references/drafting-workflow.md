# Draft production handoff

Read when a writer-ready brief is being turned into an article. Use [write-content](../SKILL.md) as the canonical entrypoint.

## Method

1. Confirm the brief, approved facts, reader task, brand context and intended page owner.
2. Develop the explanation and examples from actual research and first-party input.
3. Coordinate metadata, internal links and required media with the relevant methods.
4. Review the completed article in context and save it through the current project draft conventions.

## Deliverable

Return the article and any requested metadata/assets handoff; publication is a separate operation.
