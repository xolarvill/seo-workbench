# Draft delivery handoff

Read when an approved article needs metadata and CMS delivery preparation. Use [write-content](../SKILL.md) as the canonical entrypoint.

## Method

1. Confirm the destination platform, resource type, project binding and requested saved state.
2. Check the body, title, description, slug, author, taxonomy, assets and contextual links against approved facts.
3. For Workbench-managed content, inspect the existing content queue and publish-dry-run interface before any authorized write.
4. Record draft, saved, scheduled and publicly verified states accurately through the project workflow.

## Deliverable

Return a platform-specific delivery package, validation results and remaining implementation inputs.
