# Wording diagnostics within the reader method

Use [reader-led writing and review](../../reader-experience-review/SKILL.md) for all prose decisions. This reference supplies examples for an observed wording problem; it is not a separate editing pass, word blacklist or approval gate.

| Observed problem | Diagnostic question | Possible local change |
|---|---|---|
| Inflated or vague wording | Which property, action or fact does the reader need? | State the supported detail with an appropriate term |
| Empty transition | Does it explain a real relationship? | Remove the filler or connect the actual ideas |
| Ambiguous reference | Can the reader identify the object or actor? | Name it consistently |
| Repeated explanation | Does the repetition serve a distinct step or safety need? | Merge redundant text while preserving useful repetition |
| Invented disagreement | Which introduced claim or actual choice is being answered? | Give the supported point directly |
| Verification language in the article | Does this condition change the reader's interpretation or action? | Use [evidence to prose](../../reader-experience-review/references/evidence-to-prose.md) |

A technical term, negative instruction, list of three or run of short sentences can remain unchanged. Use the reader method's decision test before editing and check the affected meaning afterward.

For a requested wording audit, report the relevant findings using the reader method. During drafting or direct editing, apply the necessary change and keep its diagnostic notes in the existing task artifact; do not append this checklist or an internal gap list to finished copy.
