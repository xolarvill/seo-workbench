# Existing-page brief and business relevance

Use with [content-brief](../SKILL.md) for a scoped update or a new page whose proposed coverage needs a business-fit check.

## Existing page

Read the current page and the requested outcome. Use adequate existing research; collect only missing evidence needed for this decision. Return a section-level plan:

| Decision | Include |
|---|---|
| Keep | Accurate, useful explanations and their evidence/links |
| Strengthen | Specific confusion, outdated detail or missing step; proposed adjustment and its source |
| Add | A relevant unanswered reader question and the evidence needed to answer it |

Name removals or replacements when warranted; do not force every category to contain an edit. Retain the user's scope and indicate which existing sections remain. A useful existing page need not be rewritten to match a competitor's outline.

## Business relevance

Read the selected project's context and observed products/services. Recommend what the site can credibly explain, and distinguish that explanation from what it actually sells or performs. A monitor-arm seller can explain display connections without claiming to sell cables. Do not invent categories, services, stock, expert credentials or tests to fill a content template.

For a hub, connect relevant observed child pages and explain what each helps the reader do. Partial inventory leaves coverage incomplete; it does not establish that a category is absent. For a focused article, link only the relevant next tasks.

Keep the actual SERP result types in research. A forum or reference site can answer the same reader question as a shop; commercial-peer comparisons are a separate analytical subset. Do not discard a result merely because it is on a source pack's domain blacklist.

## Deliverable

Return the requested outline or change plan, supported metadata options, useful internal destinations and specific evidence gaps. Match the amount of detail to the handoff. Do not impose per-section word counts, keyword placement quotas, fixed metadata lengths or a synthetic competitor score.
