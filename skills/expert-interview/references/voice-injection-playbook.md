# Voice and Register: Shared Method

This compatibility path is retained for existing expert-interview references. Use the current [Voice and Register method](../../write-content/references/voice-injection-playbook.md) as the shared entrypoint; do not maintain a second voice-injection recipe here.

For interview handoff, preserve the expert's actual terminology, attribution and conditions. Use first-person material only when it reflects genuine involvement and helps the reader. A clear technical explanation needs no invented persona, contrarian opinion, story, emotional texture or deliberate imperfection.

The original source links remain below for provenance, not as instructions to imitate human authorship or satisfy novelty quotas.
