# Content work priorities

Read when multiple research angles need to become an actionable content queue. Use [content-strategy](../SKILL.md) as the canonical entrypoint.

## Method

1. Combine applicable quick-win, competitive-gap, page-performance, topic and trend evidence.
2. Separate improvements to existing owners from justified new pages.
3. Prioritize the observable problem, relevance, effort, dependencies and delivery capacity.
4. Choose a bounded review window and expected metric for each item; preserve the basis in the existing task artifacts.

## Deliverable

Return an ordered set of proposed work with owners, evidence, dependencies and review dates.
