# Content calendar planning

Read when approved content priorities need a realistic delivery calendar. Use [content-strategy](../SKILL.md) as the canonical entrypoint.

## Method

1. Read the proposed work, cluster dependencies, existing capacity and target reporting period.
2. Schedule research, updates and new pages according to actual prerequisites and review effort.
3. Distinguish planned editorial dates from saved publication schedules and completed releases.
4. Keep deferred opportunities and their reasons with the same planning artifact.

## Deliverable

Return a dated plan with content owner, task, dependency, delivery status and deferred work.
