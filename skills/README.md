# Skills

Extracted SEO playbooks live here as local, harness-neutral modules.

Current minimum set:

- `keyword-deep-dive` - SERP and keyword opportunity analysis.
- `content-brief` - writer-ready SERP-based article brief.
- `technical-audit` - technical SEO audit categories and output shape.

Agents should read the relevant `SKILL.md` and only load `references/` files named by that skill.
