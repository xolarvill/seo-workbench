# Local skills: choose by task

Start from the user's goal, current project decisions, artifacts and evidence. Find the matching task below, then read that `SKILL.md` before applying its method. A specific request can go straight to its specialist. Use [seo](seo/SKILL.md) when the scope itself needs sorting out.

This is navigation, not an allowlist or a required sequence. Combine methods only where the task benefits; search local modules when these examples do not fit. Inputs below describe useful evidence, not a questionnaire or a reason to block on every missing field. Reuse adequate current artifacts and ask only for essential missing information. Outputs describe possible deliverables; the user's requested scope and format control delivery.

## Find the right task

| What the user needs | Go to |
|---|---|
| Decide priorities, audiences, topics or page ownership | [Context and strategy](#context-and-strategy), [Search research and architecture](#search-research-and-architecture) |
| Write an article, refresh a page, edit a paragraph or prepare a CMS draft | [Writing and editing](#writing-and-editing) |
| Diagnose ranking, content, metadata or credibility | [Page and search experience](#page-and-search-experience) |
| Inspect crawling, rendering, structured data, images or regional SEO | [Technical and specialist SEO](#technical-and-specialist-seo) |
| Explain a traffic change, compare releases, inspect links or check tracking | [Measurement and links](#measurement-and-links) |
| Improve a landing page, form, popup, registration, activation or upgrade | [Conversion and experiments](#conversion-and-experiments) |
| Prepare emails, social posts, ads or a launch | [Distribution and launch](#distribution-and-launch) |
| Choose pricing, referrals, free tools or growth tactics | [Offers and growth](#offers-and-growth) |

For all reader-facing prose, [reader-experience-review](reader-experience-review/SKILL.md) is the single expression method during drafting and revision. Domain skills supply research, offer facts, structure and execution. Voice samples are inputs; editing references are diagnostics. They do not require separate style passes. Use [evidence to prose](reader-experience-review/references/evidence-to-prose.md) to turn evidence into supported claims and reader-useful conditions; keep internal verification notes in the existing task artifact.

## Resume and execute

Read the existing decision or brief, latest artifact, evidence pointers and remaining gaps. Reuse research when its target, market, date and scope still apply. A legacy phase or checked step cannot schedule work or prove a method complete. Read only references needed for this task; record the chosen method, material omissions and remaining gaps in the existing task artifact. Keep operational evidence there and deliver reader-facing copy in the requested format.

For collection, credentials or delivery, read [Workbench operations](seo/references/workbench-operations.md) and the relevant command's help. Use the local CLI for explicit operations. Project-specific skills add store facts, assets and delivery formats; discover them inside the current project and follow its `AGENTS.md`.

Specialist references live with their owners: [article editing](copy-editing/references/article-editing.md), [internal links](topic-cluster-planning/references/internal-link-review.md), [metadata options](page-audit/references/metadata-writing.md), [SEO editing](improve-content/references/seo-editing.md) and [conversion reasoning](page-cro/references/conversion-analysis.md).
