# Skills

Extracted SEO playbooks live here as local, harness-neutral modules.

Current minimum set:

- `keyword-deep-dive` - SERP and keyword opportunity analysis.
- `content-brief` - writer-ready SERP-based article brief.
- `write-content` - full article drafting from a brief or SERP research.
- `topic-cluster-planning` - hub/spoke content architecture.
- `page-audit` - page-level SEO/content audit.
- `eeat-audit` - E-E-A-T review and fast wins.
- `semantic-gap-analysis` - entity and subtopic gap analysis.
- `headless-precheck` - local raw HTML and sitemap evidence precheck.
- `technical-audit` - technical SEO audit categories and output shape.
- `schema` - Schema.org analysis and JSON-LD generation.
- `sitemap` - sitemap review and recommendations.
- `images` - image SEO review.
- `drift` - baseline and comparison rules.
- `linkbuilding` - off-page strategy.
- `backlinks` - backlink audit.

Agents should read the relevant `SKILL.md` and only load `references/` files named by that skill.
