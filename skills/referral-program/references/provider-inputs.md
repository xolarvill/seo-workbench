# Referral provider inputs

Start with the program objective, eligibility, reward economics, qualifying event, refund/reversal rules, attribution window and existing customer journey.

| Source | Evidence to obtain |
|---|---|
| Rewardful / Tolt / Mention Me | Program rules, referral states, conversion definition and reporting window |
| Dub.co | Link and campaign definitions, redirect destination, attribution scope |
| Stripe or other payment system | Aggregate qualifying payment and refund evidence, currency, commission basis |

Discover available provider tools rather than assuming the original pack's integrations are installed. Supplied rules and aggregate exports can support a design or review. Distinguish referral clicks, attributed conversions, earned rewards and paid rewards. Deliver program rules and a reconciliation plan; changes to rewards, payment or live program settings need authorization for those operations.
