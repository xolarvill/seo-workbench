# Email provider inputs

For sequence drafting, collect the audience, trigger, desired action, timing, suppression conditions, existing message and landing-page context. Read existing project context before asking for missing material.

For Customer.io, Mailchimp, Resend, SendGrid or Kit implementation, discover which provider operations are actually connected. Obtain the account/workspace, segment definition, trigger events, template format, sender identity and unsubscribe/suppression behavior from the selected provider or supplied export. Load a relevant installed provider skill when it applies and use its current API contract.

Deliver subjects, bodies, trigger/delay rules and a provider-specific handoff. A draft is complete without a sending connection. Creating a sequence, activating automation and sending messages are separate operations; perform only the operations the user authorized and read back their actual state.
