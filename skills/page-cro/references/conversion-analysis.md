# Conversion reasoning

Read when a landing page needs an explanation of likely conversion friction. Use [page-cro](../SKILL.md) as the canonical entrypoint.

## Method

1. Identify the intended visitor, arrival context and one primary conversion action.
2. Inspect cognitive effort, choice overload, message clarity, perceived risk, proof and action visibility.
3. Tie objections to actual offer conditions or customer evidence. Identify where the page supplies or lacks the relevant answer.
4. Separate observed friction from a behavioral hypothesis. Design a test with an explicit success metric and guardrail when causal evidence is needed.

## Deliverable

Return the observed page element, proposed mechanism, supporting evidence, recommended change and testable hypothesis.
