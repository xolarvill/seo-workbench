# Landing-page review

Read when a landing page needs a practical conversion review. Use [page-cro](../SKILL.md) as the canonical entrypoint.

## Method

1. Review the first screen for audience, offer, value and a recognizable next action.
2. Trace the main action through the page, including form effort, CTA consistency, distractions and mobile layout.
3. Check whether proof and relevant conditions appear where the visitor needs them.
4. Prioritize a small set of changes by the actual blockage and available evidence, then define how the changed journey will be checked.

## Deliverable

Provide page-location findings, an ordered action list and proposed experiments, without treating a heuristic score as a measured conversion lift.
