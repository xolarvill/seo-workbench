# Landing-page audit handoff

Read when a landing page needs conversion diagnosis. Use [page-cro](../SKILL.md) as the canonical entrypoint.

## Method

1. Establish the acquisition context, visitor, offer and intended action.
2. Inspect message match, first-screen clarity, CTA path, proof, form effort and mobile use.
3. Use available observations or recordings for actual behavior; treat inferred mechanisms as hypotheses.
4. Prioritize repairs and experiments, linking each to a clear measurement and guardrail.

## Deliverable

Return located findings, proposed changes and experiments; no scoring script or automatic publication is required.
