# Competitor landing-page review

Read when an inspected competitor landing page may inform a conversion decision. Use [page-cro](../SKILL.md) as the canonical entrypoint.

## Method

1. Record the actual page, offer, intended visitor and primary action.
2. Inspect the headline, value explanation, CTA strategy, proof, risk reduction and journey.
3. Distinguish visible strengths from assumed performance; competitor conversion rates are unknown without evidence.
4. Translate useful observations into the current site's factual offer and testable hypotheses.

## Deliverable

Return observed page elements, relevance to the current offer and changes worth testing.
