# SEO Method Selection

Read [the task index](../README.md), the current project's guidance and relevant existing artifacts. Select methods from the actual question and available evidence.

| Question | Method |
|---|---|
| Full-site or multi-template diagnosis | [site-audit](../site-audit/SKILL.md) |
| One URL's page/content/technical review | [page-audit](../page-audit/SKILL.md) |
| Technical diagnosis | [technical-audit](../technical-audit/SKILL.md) |
| Query opportunity and page ownership | [keyword-deep-dive](../keyword-deep-dive/SKILL.md), [topic-cluster-planning](../topic-cluster-planning/SKILL.md) |
| Writer-ready scope or an article | [content-brief](../content-brief/SKILL.md), [write-content](../write-content/SKILL.md) |
| Structured data | [schema](../schema/SKILL.md) |
| Pages generated from a dataset | [programmatic-seo](../programmatic-seo/SKILL.md) |

Use only the relevant methods; a small review does not require the full audit or production pipeline. Continue from current decisions and evidence rather than legacy phase status.

The Workbench CLI executes explicit operations. Upstream slash commands, agents and scripts are not installed executors. [Adapted orchestration coverage](references/upstream-orchestration.md) preserve source coverage and shared references; read a relevant section only when needed.
