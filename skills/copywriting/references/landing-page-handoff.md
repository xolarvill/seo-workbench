# Landing-page implementation handoff

Read when approved landing-page copy needs to be handed to the site implementation owner. Use [copywriting](../SKILL.md) as the canonical entrypoint.

## Method

1. Confirm the actual platform, target page type, existing page/template and requested publication state.
2. Prepare the copy, metadata, media, links, indexing intention and required data in the platform's expected form.
3. Use the current project's implementation and review path; the original WordPress executor is not an installed Workbench capability.
4. For an authorized save or release, preserve a rollback path and verify saved output and public behavior as appropriate.

## Deliverable

Deliver a reviewable implementation package and explicit current state; do not turn a copy handoff into automatic publication.
