# Landing-page draft

Read when a landing-page brief is ready for copy. Use [copywriting](../SKILL.md) as the canonical entrypoint.

## Method

1. Read the research, approved offer, audience language and conversion goal.
2. Build a message hierarchy covering value, mechanism, supporting proof and the next action.
3. Write each section and CTA for its place in the journey, using factual proof and offer conditions.
4. Coordinate headline alternatives and conversion review when relevant, then save a draft in the current project.

## Deliverable

Return the page copy, metadata and implementation notes requested by the brief; keep deployment state separate.
