# Headline alternatives

Read when a landing page needs distinct headline options or a headline experiment. Use [copywriting](../SKILL.md) as the canonical entrypoint.

## Method

1. Read the audience, offer, differentiator, factual support and intended conversion.
2. Develop distinct hypotheses such as benefit, audience fit, specific problem, outcome mechanism or comparison.
3. Pair headlines with a supporting subheadline where needed, checking that the page fulfills the promise.
4. Explain the intended audience and hypothesis for each option; select an experiment only when the measurement and traffic permit it.

## Deliverable

Provide headline/subheadline options with evidence checks and a proposed comparison metric, without predicted lift presented as fact.
