# Advertising provider inputs

Use the campaign brief and current account exports to choose the analysis. Google Ads, Meta Ads, LinkedIn Ads and TikTok Ads require account identity, date window/timezone, currency, objective, spend, delivery, conversion definition and attribution window. Creative reviews also need the actual ad and destination page. Preserve each platform's attribution definition when comparing results.

Discover available connected operations for the selected platform; this repository does not bundle the original pack's advertising connectors. Use a supplied export when access is unavailable. For website behavior, use [analytics-tracking](../../analytics-tracking/SKILL.md) with the matching property/window; platform conversions and GA4 outcomes have different scopes.

Deliver campaign and creative recommendations with the input filters recorded. Campaign creation, budget changes and launch require the user's authorization for those specific operations; an analysis request supplies no spending instruction.
