# Existing-page diagnosis

Read when an existing article needs diagnosis before a refresh decision. Use [page-audit](../SKILL.md) as the canonical entrypoint.

## Method

1. Locate the current page text and distinguish it from old drafts or captures.
2. Review intended task, publication/update context, evidence freshness and relevant observed performance.
3. Identify useful existing sections, missing answers, outdated facts and structure or internal-link issues.
4. Choose whether a local edit, substantive refresh or further research is justified.

## Deliverable

Provide the diagnosis, retained strengths, evidence gaps and a bounded recommendation.
