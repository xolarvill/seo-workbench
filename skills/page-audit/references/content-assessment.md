# Content assessment

Read when a completed page needs an evidence-based content assessment. Use [page-audit](../SKILL.md) as the canonical entrypoint.

## Method

1. Extract the page purpose, target intent, title, headings, main content, links, author and observation date.
2. Compare delivered answers with the intended reader task and applicable competitive research. Describe competitor coverage only from inspected material.
3. Inspect unclear explanations, unsupported claims, repetition, outdated facts and missing decision criteria.
4. Use actual technical and performance evidence where available; keep readability observations and professional judgments distinct from measured metrics.

## Deliverable

Provide an intent assessment, concrete strengths and gaps, and prioritized changes with page locations and source pointers.
