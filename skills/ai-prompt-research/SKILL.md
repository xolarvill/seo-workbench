# AI prompt research

Find useful questions to investigate, distinguish their origin and propose a bounded observation set.

Read project audience, product, market, brand aliases, competitors and previous research. Reuse supported facts; an inferred audience is a hypothesis, not a replacement for approved positioning. Start from customer/support language, GSC/site-search queries and community questions when available. PAA and provider question datasets can supply candidates but are not logs of AI users or AI query frequency.

Use the discovery procedure in [citation research](../seo-geo/references/citation-research.md) when model-generated phrasings help. It is optional: an adequate supplied set needs no model ideation. Preserve exact wording, seed and provenance; normalize duplicates across seeds and group by learning, choosing, doing and branded intent. Keep branded questions separate from neutral discovery questions.

For provider datasets, verify actual tool availability, market/language coverage, dates, costs and pagination. Read [provider selection](../seo-dataforseo/SKILL.md) only when needed. Dataset answers, a fresh API spot check and consumer-platform captures are separate evidence types; never mix their rates or imply API output represents all consumer sessions.

Rank groups by business/customer fit, then breadth of distinct relevant questions and observed citation patterns where available. Read decisive cited pages before describing them. Empty citation lists mean no citations were returned, not proof the answer cites nobody. Lack of a dataset match is not proof of no demand.

Deliver candidate groups with example exact prompts, provenance, market, research date, recorded answers/sources if available, and rejected groups with reasons. Propose a frozen neutral observation set and a separate branded set; sample size follows the task, not a quota. A model-only set remains exploratory. Counts describe this dataset, not people, search frequency, traffic or revenue.

Save research in the existing project task artifact. Research alone does not add a tracker, buy answer collection, change schedules or select strategic keywords. Hand an approved observation set to [ai-visibility-audit](../ai-visibility-audit/SKILL.md); use [keyword-research](../keyword-research/SKILL.md) for Google keyword opportunities.
