# Existing-page refresh

Read when an existing article needs a scoped refresh rather than a new unrelated page. Use [improve-content](../SKILL.md) as the canonical entrypoint.

## Method

1. Read the existing article, its current purpose and applicable performance/research evidence.
2. Identify what to retain, update, add or remove, distinguishing facts from editorial changes.
3. Revise the affected sections under the canonical improvement method, preserving useful links and evidence.
4. Review meaning, page ownership and the requested delivery state before handing off.

## Deliverable

Return the requested revised draft or passages. Keep change rationale and supporting evidence in the existing task artifact, or a separate editorial report when requested.
