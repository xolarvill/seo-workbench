# Targeted optimization

Read when a draft or page needs specific SEO improvements. Use [improve-content](../SKILL.md) as the canonical entrypoint.

## Method

1. Identify the actual issue and intended reader action before expanding scope.
2. Inspect the relevant metadata, headings, topic coverage, internal links and visible structured data.
3. Make a targeted proposal using the corresponding current method; substantial research or rewriting needs an actual task reason.
4. Preserve the original artifact and verify the authorized edit against its affected output.

## Deliverable

Return targeted recommendations or edits with their locations, supporting facts and verification state.
