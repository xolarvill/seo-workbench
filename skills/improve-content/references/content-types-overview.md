# Content-type selection

Use the shared [content-type overview](../../write-content/references/content-types-overview.md) to choose a structure from the actual intent, reader task and approved brief. The adjacent templates are optional patterns; a comparison, story, FAQ or counterargument belongs only when it serves this page. Lengths and heading patterns are planning aids rather than acceptance quotas. Apply [reader-experience-review](../../reader-experience-review/SKILL.md) to the actual revised prose.
