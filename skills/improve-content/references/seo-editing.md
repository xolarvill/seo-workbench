# SEO editing review

Read when a researched article needs focused on-page improvements. Use [improve-content](../SKILL.md) as the canonical entrypoint.

## Method

1. Confirm the primary intent and page owner from the brief and existing inventory.
2. Inspect whether title, introduction, headings, answers, metadata and links support that intent.
3. Use actual research to identify missing questions or useful result formats; preserve sections that already serve the reader.
4. Coordinate factual, structural, linking and metadata changes through the canonical improvement method, retaining the before/after rationale.

## Deliverable

Provide location-specific edits grouped by intent, structure, evidence, metadata and internal links, with remaining evidence gaps.
