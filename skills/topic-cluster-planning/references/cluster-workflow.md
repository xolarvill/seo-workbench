# Cluster planning handoff

Read when a topic is moving from research to a hub/spoke production plan. Use [topic-cluster-planning](../SKILL.md) as the canonical entrypoint.

## Method

1. Restore the keyword research, current page inventory and topic decisions.
2. Determine the hub, distinct spoke tasks and any existing pages to retain or strengthen.
3. Specify the useful links, their destinations and the order in which prerequisites must be completed.
4. Pass page-specific scope and evidence requirements to content-brief; retain overlap decisions and outstanding inputs.

## Deliverable

Deliver the ownership map, link plan and a dependency-aware production sequence.
