# Internal-link review

Read when an article or cluster needs contextual link recommendations. Use [topic-cluster-planning](../SKILL.md) as the canonical entrypoint.

## Method

1. Read the source passage and inventory of eligible existing destination pages, including their owners and purposes.
2. Choose links that help the reader continue a task, understand a concept or compare an offer.
3. Specify the source passage, destination, anchor wording and reason. Check canonical destinations and avoid competing page owners.
4. Record planned links to unpublished pages separately from working links. Verify actual placement after an authorized edit.

## Deliverable

Return a link recommendation table and any reciprocal links to review. Do not infer orphan status from incomplete graph coverage.
