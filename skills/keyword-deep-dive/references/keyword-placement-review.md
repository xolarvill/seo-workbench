# Keyword placement review

Read when a draft needs its main topic and supporting terms mapped to page sections. Use [keyword-deep-dive](../SKILL.md) as the canonical entrypoint.

## Method

1. Confirm primary and secondary terms against observed intent and the intended page owner.
2. Map the title, H1, introduction, relevant headings, main explanations and descriptive link anchors.
3. Check whether terms explain the subject in context, whether a section repeats the same idea, and whether important related concepts are missing.
4. Coordinate changes with the brief and current writing method; observations about term occurrence are not a separate density acceptance gate.

## Deliverable

Provide a term-to-section map, observed placements, clarity gaps and targeted recommendations.
