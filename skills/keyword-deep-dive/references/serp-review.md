# SERP review

Read when a query needs a closer result-format and intent analysis. Use [keyword-deep-dive](../SKILL.md) as the canonical entrypoint.

## Method

1. Record query, market, language, device where applicable and observation date.
2. Inspect the returned results and record actual page types, heading patterns and visible SERP features.
3. Read relevant result pages to compare the questions answered, evidence offered and scope.
4. Translate the observations into page requirements and uncertainties; competitor length remains an observation rather than an automatic target.

## Deliverable

Return the result evidence, dominant or mixed intent, useful formats and writer-facing requirements.
