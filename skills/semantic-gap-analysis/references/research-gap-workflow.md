# Competitor coverage gaps

Read when competitive evidence is being used to find missing useful coverage. Use [semantic-gap-analysis](../SKILL.md) as the canonical entrypoint.

## Method

1. Choose competitors and comparison pages relevant to the same task and market.
2. Compare observed query/page coverage and inspected sections, excluding irrelevant branded or unrelated opportunities.
3. Distinguish topic gaps, missing depth and evidence/quality gaps from missing provider observations.
4. Map each useful opportunity to an existing owner, a justified new page or an explicit research question.

## Deliverable

Provide the gap, supporting source pages, current owner, relevance and recommended work.
