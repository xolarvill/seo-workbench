# Periodic content performance review

Read when content outcomes are being reviewed across an explicit reporting period. Use [drift](../SKILL.md) as the canonical entrypoint.

## Method

1. Collect the already available performance artifacts, their exact windows and measurement regimes.
2. Compare observed pages and content groups with the prior comparable period.
3. Investigate large movements using query/page composition and known content changes.
4. Describe associations and follow-up work without treating a date overlap as causal attribution.

## Deliverable

Return a source-bound performance readout, prioritized follow-ups and a future review date.
