# Performance-based priorities

Read when a content inventory needs descriptive performance grouping. Use [drift](../SKILL.md) as the canonical entrypoint.

## Method

1. Use the same page identity and comparable windows across the sources available.
2. Compare visibility/ranking observations with traffic and engagement while keeping their metric definitions separate.
3. Group pages descriptively by observed strength, opportunity or decline; do not treat a quadrant as a diagnosis.
4. Assign a next diagnostic question before recommending refresh, consolidation or metadata changes.

## Deliverable

Return grouped pages and the evidence-backed question or proposed action for each group.
