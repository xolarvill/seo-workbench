# <项目名> 周报 · YYYY Week WW（MM-DD → MM-DD）

## 速览

> 同时记录两类任务：① 本周待完成（本周新增，或上周"遗留工作"移入）；② 已确认遗留到下周的任务。完成项用最简语言打勾，未完成项一律留空（含已决定遗留到下周的项）。
> **格式固定规则**：不使用 `###` 层级；大任务为顶层 checkbox，子任务用 4 空格缩进对齐（可多级），同一主题的散项并入一个大任务下。所有周报统一按此格式。

- [x] 大任务 1（一句话概括，可带日期）
    - [x] 子任务 1
    - [x] 子任务 2
    - [ ] 子任务 3（未完成）
- [ ] 大任务 2（未完成）
- [x] 大任务 3：一句话说明本周已完成事项
- [ ] 一句话说明已确认遗留到下周的事项（对应"遗留工作"）

## 实质工作

> 完成事项的具体内容。要点式、点到即止；复杂细节链接到对应子报告，不在周报内展开。
> **格式固定规则**：① 各节按任务完成时间先后顺序写入（编号随顺序递增）；② 节标题以 `（日期）` 结尾（如 `### 3. 测量口径台账（08-17）`），与既有格式一致。

- 要点 2
- 详情：`reports/YYYYMMDD_<category>_<topic>.md`；证据：`audits/...`

- 要点 1

## 遗留工作

> 只收录本周之内无法完成、需移出本周的任务（含上周遗留、本周仍无法完成而继续顺延的项），每项附状态与后续日期。本周待完成的任务不写入本板块，仅在速览中留空；下一周开始时，本板块条目移入新一周速览的"本周待完成"。**本板块只允许未完成项：本周内完成的任务必须移出，细节写入实质工作、速览打勾，不得以勾选/emoji 形式停留在此。**
> **格式固定规则**：与速览一致——扁平 checkbox 列表、不用 `###`、同类项可用 4 空格缩进分组；**不添加"（新）"等时效性标注**（每项本身就是本周无法完成的项，来源/时间写在项内表述或实质工作里）；每项按 `**<任务名>**：<无法完成的原因>；后续：<日期> <动作>` 固定结构。

- [ ] **<任务名>**：<本周内无法完成的原因>；后续：<日期> <动作>
    - [ ] <同主题子项 1>：<原因>；后续：<日期> <动作>
- [ ] **<任务名>**：<本周内无法完成的原因>；后续：<日期> <动作>
