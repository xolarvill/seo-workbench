# Agent按目标选择本地 SEO 方法

日期：2026-10-26。状态：本轮已实施目标驱动入口、任务索引与next调度退役；来源模块的逐项再适配按后续实际任务推进。依据：[原始诊断](20261026-local-skill-integration-diagnosis.md)。

## 已批准的架构调整

用户确认取消next调度，由agent依据当前目标和证据选择所需方法。先前提议“给next增加guidance”已取消，不再以阶段状态机作为技能发现前提，也不另建一个自动任务分类器替代它。

```text
用户目标 + 项目指令 + 现有产物与证据
                  |
          agent判断缺口与选择方法
                  |
      本地skills / 工具 / 项目能力
                  |
     明确操作 → 产物、决定、证据与缺口
```

CLI执行采集、查询、校验、保存和其他明确操作；agent负责选择、组合和调整。技能是成熟方法与验收标准，既有项目文件是跨会话接续依据。

前提是运行环境允许agent读取仓库指令和文件。仓库可以提供稳定入口和可验证行为，无法强制任何模型、任何聊天环境或压缩后的会话都自动遵从。

## 入口与方法选择

- [AGENTS.md](../AGENTS.md) 开头规定从目标、项目AGENTS、现有决定与证据出发；实质SEO工作主动查阅索引并读取适用技能正文，不等用户提醒。
- [skills/README.md](../skills/README.md) 按任务提供短入口及三来源材料导航。它不是白名单，也不是必须串行运行的流程；agent可搜索其他本地模块、组合方法或只完成适用部分。
- [CLAUDE.md](../CLAUDE.md) 是共享指令的薄适配，不再推荐next或step done作为日常入口。
- [project-context](../skills/project-context/SKILL.md) 按实际文档及事实完成检查，不通过next决定下一步。

已有且仍适用的研究可以复用，复用前检查目标、市场、观察日期、范围与证据质量。一处措辞审读无需新做SERP或全文重写。上下文压缩后规则正文不可用时，只重读必要部分。

项目技能补充店铺事实、素材与交付格式；通用技能提供专业方法。当前用户授权、项目隔离、证据资格和Workbench采集边界继续有效。可自由选择方法不等于可以扩大抓取、发布或对外通信范围。

## CLI与兼容边界

- `./seo next` 已从parser和实现移除，调用时按未知命令报错，退出码2。通过 `./seo --help`、命令级help和当前目标选择明确操作。
- `status --json` 不再返回 `next` 指令；返回本地 `skill_index` 路径，帮助定位方法。phase和step仍是旧数据的兼容投影，不代表当前用户任务或推荐动作。
- UI workspace不再返回next契约；前端对应类型和调用方已移除。HTTP字段删除是本次有意接口变更；外部消费者应停止读取workspace.next，改读具体工作区与任务产物。
- 旧state中的phaseOrder、phases、history及nextAction不做批量迁移或清空。显式 `phase`／`step` 命令和原UI维护endpoint暂时保留给兼容用途；它们不验收专业成果。历史映射通过 `step_reference` 保留为参考，不再作为调度器输出。
- 维护阶段记录时不再生成“Run next”等指令。其他旧生产功能可能仍写历史nextAction备注，当前status和UI不将其提升为任务入口。

## UI与持续工作

原Plan入口改为Methods，保留 `#/workflow` 地址以兼容书签。首页提供能力地图入口与实际内容记录数量，不显示当前阶段任务、Next action或Workflow complete。

Methods地图展示所有内建能力组及项目自定义参考组。旧项目phase_order即使只有INIT、为空或全部完成，也不会隐藏研究、内容、技术等能力。不高亮当前阶段、不提供步骤Start／Mark done／Skip按钮，也不在加载时更新项目状态。

研究、brief、内容、审计和变更工作区继续保留自己的业务状态与交接。跨会话时恢复相关决定、最新产物、证据指针和缺口，不需要把整个项目重置到某个阶段。

## 三来源方法的使用

SuperSEO的研究、集群、brief、写作与审阅可按任务组合；SEO Machine的编辑、内链、元信息及转化方法已在索引中可发现；Claude SEO专项模块按具体问题查阅。能力仍保留原归属，原仓库不是运行依赖。

源码保存不意味着所有旧配方都适配当前环境。索引明确：现行证据边界优先，不盲跑旧脚本或slash命令；旧字数、关键词密度、通用评分和推测权威值不构成验收门槛。后续实际任务若需要改写专项入口，单独提交适配与相关验证，不在本轮假称63个模块已逐项认证。

## 完成与未完成的判断

在既有报告、brief或审阅产物中说明采用的方法、关键输出、复用依据与缺口。不创建通用任务数据库、第二份内容状态或全局调用计数。

读取过技能不代表完成方法；保存一个brief也不能证明SERP研究完整。专业验收检查产物与证据；结构校验检查路径和状态契约，两者不能互相替代。
